怎么接入豆包
（智能体模式）

五十秒能讲完的事：拿一个火山方舟的 Key，填进页面，短片就由豆包来定分镜、配色和 BGM。手机和电脑是同一套流程。

1

打开火山方舟

手机浏览器进 console.volcengine.com/ark，用手机号或抖音登录（新用户有免费额度）。

2

开通豆包大模型

左侧「模型广场」→ 选一个豆包模型 → 点「开通」；再进「推理接入点」确认有一个可用的接入点。

3

创建 API Key

左侧「API Key 管理」→ 创建 API Key → 复制那串以 ek- 开头的字符。只显示一次，先粘到备忘录。

4

回这里，选智能体模式

打开关系复原胶首页 → 点「智能体模式 豆包」→ 把 Key 粘进输入框 → 保存。页面顶部会显示「已接上豆包」。

5

生成一支定制短片

贴聊天记录 → 生成。豆包会把五个镜头的标题、旁白、配色和音乐性格定下来，画面和 BGM 由本机实时画出来、奏出来。

1

电脑打开火山方舟

浏览器进 console.volcengine.com/ark，注册或登录火山引擎账号。

2

开通模型与接入点

「模型广场」开通豆包模型；「在线推理 / 推理接入点」里记下模型名（默认用 doubao-seed-1-6 这一支）。

3

创建 API Key

「API Key 管理」→ 创建 → 复制 ek- 开头的 Key。可以给它起个名字，方便以后撤销。

4

填进页面

打开关系复原胶 → 智能体模式 → 粘贴 Key → 保存。Key 只存在服务器上，不会出现在网页源码里。

5

验证

随便贴一段对话生成一次，片头出现豆包写的分镜（比如「靠近 · 消息开始密起来」）就说明接上了。

两件事先说清楚：
1. 不填 Key 也能用，只是走本地分镜，片上会标「还没填豆包 Key」。
2. 这个 Key 是花钱的（按量计费，新账号通常有免费额度）；只给自己用，别贴到公开的地方。
